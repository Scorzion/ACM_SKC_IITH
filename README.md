# ACM India Summer School on Symmetric Key Cryptography (IIT Hyderabad) 🔑🎓

This repository contains my hands-on lab solutions, custom implementations, and technical LaTeX reports from the ACM India Summer School on Symmetric Key Cryptography (June 2026) at IIT Hyderabad.

## 💡 Key Highlights

* **Cryptanalysis**: Implementing linear and differential cryptanalysis attacks on DES, and simulating differential propagation for ML-based neural distinguishers on Speck32/64.
* **Ciphers from Scratch**: Implementing block ciphers like AES and DES, and stream ciphers like Salsa20.
* **Formal Methods in Lean 4**: Interactive theorem proving for list sorting, parity predicates, and list properties (from Dr. Ashish Mishra's excellent sessions).
* **Boomerang Attack Masterclass**: A special highlight was Prof. Dhiman Saha's amazing and intuitive explanation of the boomerang attack!
* **Future Tech**: Industry sessions by TCS Research covering Post-Quantum Cryptography (PQC) migration and Fully Homomorphic Encryption (FHE) for Privacy-Preserving Machine Learning.
